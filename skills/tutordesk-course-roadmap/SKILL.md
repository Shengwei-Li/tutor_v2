# Course roadmap

`roadmap.md` in the student folder plans the whole course. It is what the tutor plans from and what the parent page shows as progress.

```markdown
---
lessons: 20
---

# Wang Yiran: IELTS Academic 6.5 → 7 by 29 Dec

Weakest: writing (Task 2 position, development). Strong: listening.

## 1. Diagnose (weeks 1–2)
- [x] Diagnostic: Task 2 essay under time, speaking Parts 1–3
- [ ] Task 2 position: one clear claim, held to the end

## 2. Build (weeks 3–6)
- [ ] Developing a body paragraph (PEEL)
…

## 3. Exam practice (last 3 weeks)
- [ ] Full timed mock, review
```

## How to plan it

1. Count the lessons left: weekly slots in `schedule` up to `exam_date`. If there is no exam date, plan ten weeks and say so.
2. Start with diagnosis unless the tutor already has recent results.
3. Spend most of the time on the skill furthest from the target; for PTE the weakest skill decides, since goals are per skill.
4. Each line is one lesson with one core skill. Bring earlier skills back a few lessons later (spaced) instead of finishing a skill and leaving it.
5. End with timed practice under exam conditions.

Keep `- [ ]` lines: a lesson becomes `- [x]` when its record is written. When plans change (a missed lesson, a new weakness), revise the remaining lines and tell the tutor what moved.

Show the tutor the outline in a few lines and ask whether it fits before planning single lessons from it.
