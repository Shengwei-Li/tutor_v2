# Teaching standards

## Design rules

1. Open with retrieval: the student recalls or corrects last lesson's material from memory (5–8 min), not a re-explanation.
2. New skills: full worked example → partly completed example → independent attempt. Fade faster for stronger students.
3. Put an effective and a less effective version side by side and mark the one difference; ask the student to name it.
4. Guided practice should run at about 80% success; far lower means return to modelling.
5. Block a new task type first; interleave it with similar older types once the student can tell them apart.
6. Recycle the student's earlier errors at spaced intervals, in a new surface form each time.
7. Student produces first, compares with a model and finds the gap; then the tutor adds.
8. Focused correction: one or two error types per piece of work. Weaker students get the correct form; stronger students get a code and correct it themselves.
9. Pre-task → task → language focus. The student speaks or writes for at least half the lesson; the tutor never talks for more than five minutes at a stretch.
10. One emphasis style per page, at most three emphasised items; glosses next to the word; slides carry no tutor script.

## Review checklist

Score each item 1–5 (1 missing or wrong, 3 present but generic, 5 specific and ready). Anything below 4 gets fixed before the tutor sees it. Items marked **gate** must be right, not just good.

**Every plan and material**
- Objectives are observable, each with how it is checked.
- Personal: uses at least two of the student's own errors or sentences, with evidence.
- Pitched half to one band above the current level, not band-9 showpieces.
- One-to-one wording: never "class", "everyone" or group work.
- **gate** Exam facts only from the exam skill; no promised score gains.
- **gate** Every model or revised sentence meets the lesson objective and is correct English.

**Plan**: retrieval → model → guided → independent → check; one core skill; timings realistic and adding up.

**Handout**: accurate, dense, no generic study tips; room to work on the page; readable in black and white.

**Worksheet**: aligned with the objectives; **gate** every answer correct and unambiguous; **gate** exam format faithful (TFNG legend, word limits); instructions say what to write, how much and how long; texts original.

**Script**: **gate** times add up; sayable tutor talk with expected answers; diagnostic questions (never "Do you understand?"); two fallback plans.

**Slides**: titles state the point; one idea per frame; real student sentences in compare frames with errors marked and explained; ends with an exit check.
